The model

  • a building is a dataset; a sheet is a file
  • a lit base means mounted
  • a bare frame holds nothing (canmount=off)

Floors on a roof are snapshots

  • a foundation version
  • a save
  • where an update starts

A glow says what this step did

  • created
  • written
  • read
  • snapshotted
  • destroyed
  • renamed away

Threads are operations, numbered as in the text

  • build, install
  • send, save
  • clone
  • rebase
  • rename, promote
